# Kebijakan Privasi Jago Basisdata / Jago Database

*Privacy Policy for Jago Database* — [English version below](#privacy-policy-jago-database)

**Berlaku sejak:** 1 November 2026
**Pengembang:** SUTRIADI WEB
**Kontak:** support-jago-database@sutriadi.com
**Aplikasi:** Jago Basisdata / Jago Database (`com.sutriadi.dbmaestro`)

## Ringkasan

Jago Basisdata tidak mengumpulkan, menyimpan di server, membagikan, atau menjual data pribadi Anda. Semua data aplikasi tersimpan hanya di perangkat Anda. Aplikasi hanya terhubung ke server database yang Anda masukkan sendiri.

## Data yang kami kumpulkan

Tidak ada. Pengembang tidak menerima data apa pun dari aplikasi ini. Aplikasi tidak memuat iklan, pelacak, analitik, maupun layanan pelaporan kerusakan sendiri. Pustaka pihak ketiga yang dipakai (misalnya driver database dan komponen Android) berjalan di perangkat Anda dan tidak mengirim data kepada pengembang.

## Data yang tersimpan di perangkat Anda

Agar aplikasi berfungsi, data berikut disimpan **hanya di perangkat Anda**, di penyimpanan privat aplikasi:

- **Profil koneksi:** nama profil, jenis database, alamat server, port, nama database, dan nama pengguna.
- **Kata sandi koneksi:** disimpan terenkripsi dengan Android Keystore (AES-GCM).
- **Tab dan isi editor query**, serta pengaturan tampilan (tema, skema warna).

Data ini tidak ikut dicadangkan ke layanan awan (pencadangan otomatis Android dimatikan) dan tidak pernah dikirim ke pengembang. Menghapus data aplikasi atau mencopot pemasangan aplikasi menghapus semuanya.

## Koneksi jaringan

Aplikasi memakai izin internet hanya untuk terhubung ke **server database yang Anda masukkan sendiri**. Tidak ada koneksi ke server pengembang.

- Isi database Anda ditampilkan, diubah, dan diekspor hanya atas perintah Anda.
- Opsi SSL mengenkripsi koneksi tetapi **tidak memverifikasi sertifikat server**. Tanpa opsi SSL, data dapat terkirim tanpa enkripsi. Keamanan jalur ke server menjadi tanggung jawab konfigurasi Anda.

## Berkas Anda

Aplikasi membuka dan menyimpan berkas (ekspor, backup, dan berkas `.sql`) hanya melalui pemilih berkas bawaan Android (Storage Access Framework), dan hanya berkas atau lokasi yang Anda pilih sendiri. Aplikasi tidak memindai penyimpanan Anda. Berkas hasil ekspor dan backup **tidak dienkripsi** dan dapat berisi data sensitif dari database Anda; Anda bertanggung jawab atas penyimpanan dan pembagiannya.

## Izin

Aplikasi hanya meminta izin **internet**, untuk terhubung ke server database Anda. Aplikasi tidak meminta izin penyimpanan luas, lokasi, kontak, kamera, atau mikrofon.

## Pembelian dalam aplikasi

Aplikasi ini gratis, dengan fitur lanjutan (Pro) yang dapat dibeli lewat Google Play. Pembelian, pembayaran, dan pengembalian dana diproses sepenuhnya oleh Google Play dan tunduk pada [Kebijakan Privasi Google](https://policies.google.com/privacy). Aplikasi hanya menerima status pembelian (sudah atau belum Pro), dan pengembang hanya menerima laporan penjualan agregat dari Google, tanpa data pembayaran Anda. Google juga dapat mengumpulkan data teknis (misalnya laporan kerusakan Android vitals) dari perangkat yang mengizinkannya; itu berada di luar kendali aplikasi ini.

## Anak-anak

Aplikasi ini ditujukan untuk pengguna berusia 18 tahun ke atas dan tidak sengaja mengumpulkan data dari anak-anak. Karena aplikasi tidak mengumpulkan data apa pun, tidak ada data anak yang tersimpan oleh pengembang.

## Keamanan

Karena data tidak meninggalkan perangkat selain ke server yang Anda pilih, keamanannya bergantung pada perlindungan perangkat Anda (kunci layar, enkripsi, pembaruan sistem) dan konfigurasi server database Anda. Berkas yang Anda simpan ke penyimpanan bersama atau layanan awan melalui pemilih berkas tunduk pada kebijakan penyedia penyimpanan tersebut.

## Hak Anda

Karena pengembang tidak menyimpan data pribadi Anda, tidak ada data yang dapat diakses, diperbaiki, atau dihapus dari sisi pengembang. Anda dapat menghapus seluruh data lokal kapan saja lewat pengaturan Android (Info aplikasi → Penyimpanan → Hapus data) atau dengan mencopot aplikasi.

## Perubahan kebijakan

Jika fungsi aplikasi berubah sehingga memengaruhi privasi, kebijakan ini akan diperbarui sebelum perubahan dirilis, dan tanggal "Berlaku sejak" akan diubah. Versi terbaru selalu tersedia di alamat tempat dokumen ini diterbitkan.

## Kontak

Pertanyaan tentang kebijakan ini: support-jago-database@sutriadi.com.

# Privacy Policy: Jago Database

**Effective date:** 1 November 2026
**Developer:** SUTRIADI WEB
**Contact:** support-jago-database@sutriadi.com
**App:** Jago Basisdata / Jago Database (`com.sutriadi.dbmaestro`)

## Summary

Jago Database does not collect, transmit to any server of ours, share, or sell your personal data. All app data stays on your device. The app connects only to the database servers you enter yourself.

## Data we collect

None. The developer receives no data from this app. The app contains no ads, trackers, analytics, or crash-reporting services of its own. The third-party libraries it uses (for example database drivers and Android components) run on your device and do not send data to the developer.

## Data stored on your device

To work properly, the following is stored **only on your device**, in the app's private storage:

- **Connection profiles:** profile name, database type, server address, port, database name and username.
- **Connection passwords:** stored encrypted with the Android Keystore (AES-GCM).
- **Query editor tabs and contents**, and display settings (theme, color scheme).

This data is not included in cloud backups (Android automatic backup is disabled) and is never sent to the developer. Clearing the app's data or uninstalling the app removes all of it.

## Network connections

The app uses the internet permission only to connect to **the database servers you enter yourself**. It makes no connection to any developer server.

- Your database contents are displayed, modified and exported only when you instruct the app to.
- The SSL option encrypts the connection but **does not verify the server certificate**. Without the SSL option, data may be sent unencrypted. Securing the path to your server is your responsibility.

## Your files

The app opens and saves files (exports, backups and `.sql` files) only through Android's system file picker (Storage Access Framework), and only files or locations you choose yourself. It does not scan your storage. Export and backup files are **not encrypted** and may contain sensitive data from your databases; you are responsible for storing and sharing them.

## Permissions

The app requests only the **internet** permission, to connect to your database servers. It does not request broad storage, location, contacts, camera or microphone permissions.

## In-app purchases

The app is free, with advanced (Pro) features that can be purchased through Google Play. Purchase, payment and refunds are handled entirely by Google Play and are governed by [Google's Privacy Policy](https://policies.google.com/privacy). The app only receives the purchase status (Pro or not), and the developer receives only aggregated sales reports from Google, without your payment details. Google may also collect technical data (for example Android vitals crash reports) from devices that allow it; this is outside the app's control.

## Children

This app is intended for users aged 18 and over and does not knowingly collect data from children. Because the app collects no data, the developer holds no children's data.

## Security

Because data does not leave your device other than to the servers you choose, its security depends on your device's protections (screen lock, encryption, system updates) and on how your database servers are configured. Files you save to shared storage or cloud providers via the file picker are subject to those providers' policies.

## Your rights

Because the developer stores no personal data about you, there is nothing to access, correct or delete on the developer's side. You can remove all local data at any time through Android settings (App info → Storage → Clear data) or by uninstalling the app.

## Changes to this policy

If the app changes in a way that affects privacy, this policy will be updated before the change is released and the effective date will be revised. The latest version is always available at the address where this document is published.

## Contact

Questions about this policy: support-jago-database@sutriadi.com.
